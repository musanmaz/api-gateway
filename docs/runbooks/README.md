# İşletim notları

Aşağıdaki olaylar için uygulanabilir runbook henüz yoktur. Üretimde kullanılmazlar.

- Sürüm yükseltme ve geri alma
- Şema migrasyonu
- Sertifika ve anahtar dönüşümü
- Disk dolması
- Sertifika bitişi
- Trafik düğümü kaybı
- Veritabanı veya quorum kaybı
- Ağ bölünmesi
- Tam geri yükleme
- Veri merkezi kaybı

Yerel durdurma `make down` ile yapılır. Kimlik dosyaları `.local` altındadır. Bunlar silinirse eski imzalı paketler açılmaz.
